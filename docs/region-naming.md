# SEM 图片区域编号规范

状态：已接入程序。0.4.1 按 SEM 实际导出格式采用连字符分隔，替换 0.4.0 的点号区域编号；旧物理坐标命名规范继续停用。
CAD 入口只接受本规范的连字符区域编号，不再接受点号区域编号、括号坐标、`r3c4` 格式或坐标覆盖 JSON。
不带 `--cad` 的图像校正入口仍允许任意文件名。

## 四条固定规则

1. **大区域**：以数字 marker 的设计中心为中心，覆盖 200×200 µm。
2. **行列方向**：内部划分为 4×4 个 50×50 µm 方格。行 `r` 从上往下，列 `c` 从左往右，均取整数 1–4。上、下、左、右以 CAD 版图方向为准：X 向右，Y 向上；采用当前图像向右=+X、向上=+Y 的成像约定。
3. **文件命名**：明确使用 `大区域编号-行-列-序号.tif`，例如 `0303-1-4-01.tif`。所有字段用连字符分隔；末尾序号由 SEM 自动生成，只用于区分图片，不参与坐标换算。序号保留在记录中，不限制为 1–4；例如 `0303-1-4-05.tif` 与 `0303-1-4-01.tif` 定位到相同区域。也接受没有末尾序号的 `0303-1-4.tif`。大区域编号保留前导零；不使用 `(3,4)` 表示行列号，避免与旧坐标格式混淆。
4. **区域含义**：编号对应参与定位的四个十字中心围成的方格，不是 SEM 图片的外边界。图像可以包含方格外的余量。边界十字可由相邻方格共享；编号用于区分方格，不是为每个十字单独编号。

## 大区域编号与物理坐标

沿用版图数字编号约定：四位编号 `aabb` 的前两位 `aa` 表示 X 编码，后两位 `bb` 表示 Y 编码。

- 大 marker 中心：`Xc = 100 × int(aa)`、`Yc = 100 × int(bb)`，单位 µm。
- 大区域范围：`[Xc−100, Xc+100] × [Yc−100, Yc+100]`。
- 例如 `0101` 中心为 `(100,100) µm`，覆盖 `(0,0)` 到 `(200,200) µm`。

是否存在该编号的大区域，应以实际版图为准；四位数字格式合法不等于该区域一定存在。

## 小区域坐标换算

给定行号 `r`、列号 `c`，左下角（左下十字 M3）为：

```text
X0 = Xc − 100 + 50 × (c − 1)
Y0 = Yc + 100 − 50 × r
```

右上角为 `(X0+50, Y0+50)`。全部坐标单位为 µm。
四个定位标记按图像行优先排列：

- M1 左上：`(X0,    Y0+50)`。
- M2 右上：`(X0+50, Y0+50)`。
- M3 左下：`(X0,    Y0)`。
- M4 右下：`(X0+50, Y0)`。

## 固定示例

`0303-1-4-01.tif`：marker 中心 `(300,300) µm`；第 1 行第 4 列；小格左下 `(350,350)`、右上 `(400,400) µm`。

`0101-3-4-01.tif`：

- 大区域中心 `(100,100) µm`。
- 第 3 行、第 4 列。
- 左下角 `(150,50) µm`，右上角 `(200,100) µm`。
- 对应旧格式的锚点标注为 `(1.5,0.5)`，不是 `(3,4)`。

边界核对：

- `0101-1-1-01.tif`：左下 `(0,150)`，右上 `(50,200)` µm。
- `0101-4-4-01.tif`：左下 `(150,0)`，右上 `(200,50)` µm。

## 程序行为

- 仅解析 `aabb-行-列-序号`（末尾序号可省略）；旧物理坐标格式明确报错，不转换、不猜测。
- 检查行列号范围，保留大区域编号、行列号及最终微米坐标用于追溯。
- 换算出的四个设计位置已接入现有 CAD 贴图流程；区域间距固定为 50 µm。
- 一键流程在图像检测前检查命名；无效命名明确跳过，不影响其他合格图片。
- 原图改名可按内容哈希关联已有校正报告；不会自动改动原图文件名。
- 人工标注仍决定区域身份；低拟合残差不能证明人工选中的大区域或小方格正确。
